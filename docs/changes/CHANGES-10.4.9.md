# Saveit 10.4.9

## New Page button
- A **Page** button now sits in the tools rail between **Effects** and **Image**. Its icon is a sheet of paper with a folded corner and lines of writing.
- Clicking it opens a new, blank page in the text editor, ready to type in. Each click starts another page. The editor's **Save to library** keeps a page in the library under Text, the same way it keeps grabbed text.
- The button works whatever is open in the editor (an image, a video, audio or nothing).
