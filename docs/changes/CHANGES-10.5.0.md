# Saveit 10.5.0

## Vignette shows on new screenshots again
- A **Vignette** chosen for captures (or set in the Effects panel) now shades the screenshot itself. Since screenshots became a picture layer on a white base (8.13), the vignette was drawn on the base underneath, so the screenshot covered it and nothing seemed to happen.
- The vignette goes over the picture and under the arrows, boxes and text you add on top, so annotations keep their true colors.
- Exports, copies and thumbnails show it the same way.
