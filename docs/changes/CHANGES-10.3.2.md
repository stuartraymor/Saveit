# Saveit 10.3.2

- Split, Delete, Add videos, Duplicate, Undo and Redo now stay above the timeline while you work with drawing tools or sound effects.
- Selecting a timeline item shows its matching settings. Video selection keeps useful Clip, Audio or Transitions context.
- Added visible Snap and Fit controls. Alt temporarily bypasses snapping while dragging.
- Video deletion is labeled Ripple delete and explains how to keep the gap. Inapplicable actions are disabled.
- Clip properties appear before whole-timeline trim controls. Those trim controls no longer clutter other settings panels.
- Added Export file for choosing a format and destination. Save copy to Library now names its destination clearly.
- Empty caption and annotation lanes stay out of the way until used. Timeline keyboard focus is visible.
- Narrow windows scroll the editor and settings without overlapping them.

Reference and validation: VIDEO-FLOW-REVIEW-10.3.2.md. Reviewed against official Camtasia and Premiere documentation. Local update only; no public release was requested.
