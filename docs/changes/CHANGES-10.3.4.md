# Saveit 10.3.4

- Grouped clip actions, trim actions and history directly above the timeline. In/Out sits below Undo, Redo and Reset edits.
- Highlight and other annotation modes hide the clip/trim action rows. Hide timeline hides the complete timeline editing group, range fields, zoom and snapping.
- Renamed Keep selected part to Keep middle, which trims both ends. Renamed the Clip settings tab to Crop.
- Clarified Delete & close gap, Delete (keep gap), Duplicate clip and Reset edits. Replaced duplicate Play all / Restart controls with Play from start.
- Avoided duplicate visible Undo/Redo buttons while editing video; image editing retains its application history buttons.
- Multi-track timelines now scroll vertically so captions and annotations remain reachable.
- Preview buffering now retains a decoded picture, avoiding a black flash when the live media element temporarily loses its ready state.
- Added grouped-control tests and a six-minute, three-source native editing/export scenario.

See TIMELINE-REVIEW-10.3.4.md for validation and scope. No public release was requested.
