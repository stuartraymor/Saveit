# Saveit 10.3.1

- Step numbers and stamps placed on a video now save immediately, without needing another edit.
- Dragging the last clip keeps the timeline scale steady until you release it.
- Left and Right move one frame at the project frame rate. Shift still moves one second.
- Deleting a video clip and closing the gap now cuts spanning audio, captions and annotations across the same time range, keeping them together.
- Added recording-length/export checks, annotation save checks, and independent decoding checks for annotation timing. Previously deferred drag, frame-step and ripple-audio checks are now required.

See VIDEO-REVIEW-10.3.1.md for test evidence and limits. This is a local development update; publishing requires the owner's approval.
