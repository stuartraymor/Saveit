# Saveit 10.3.3

- Annotation colour and width changes now save without needing another edit. Colour changes made with the keyboard also have reliable Undo.
- The drawing controls show the selected annotation's own colour and width.
- Existing on-screen text can be edited and resized in the selected-item panel, with autosave and Undo.
- Newly added annotations, captions, zooms and effects fit inside the project duration. Moving timed items keeps their ends reachable on the timeline.
- Typed annotation/caption times stay inside the project. Caption text saves while you type, before leaving the field.
- Added a native recording-to-export walkthrough, independent export decoding, and focused annotation persistence/timing checks.

See VIDEO-JOURNEY-REVIEW-10.3.3.md for the complete workflow and evidence. Local update only; no public release was requested.
