01 / Capture & images

Take your first screenshot

Capture the area you need, then open it in the editor.

  1. Choose Image

    Select Image in the capture bar. Choose Region, Window or Full screen in Selection.

  2. Start the capture

    Click Capture. For a region, drag around the area to keep. For a window, choose it in the window picker.

  3. Confirm when prompted

    Adjust the selection if needed and click Capture. The image opens in the editor.

  4. Use a shortcut next time

    Print Screen starts a region capture. Shift + Print Screen captures a window; Ctrl + Print Screen captures the full screen.

02 / Capture & images

Explain a screenshot with markup

Use an arrow, callout, highlight or shape to make your point.

  1. Open a capture

    Capture a new image, click Open to import one, or select an image from Recent or Library.

  2. Choose a tool

    Select Arrow, Callout, Text, Highlight or another tool in the ribbon, then click or drag on the picture.

  3. Adjust its appearance

    Use the right-hand inspector and quick styles to change the selected object. Move / Select lets you reposition it.

  4. Review and share

    Use Undo and Redo to compare changes. Click Copy to share the finished picture, or Save as… to export a file.

03 / Capture & images

Magnify a small detail

Enlarge the part someone needs to read.

  1. Pick Magnify

    Open an image and select Magnify in the tool ribbon.

  2. Draw over the detail

    Drag around the text or control that needs a closer look. A magnifier shows the enlarged area.

  3. Refine the result

    Use the inspector to adjust Zoom, line width and appearance. Move or resize the object with its handles.

  4. Compare the change

    Undo removes the last edit; Redo restores it. Your underlying image remains available for editing.

Number the actions in order

06 / Capture & images

Crop to exact dimensions

Keep the useful part and remove unrelated detail.

  1. Start a crop

    Open an image, select Crop and drag around the area to keep.

  2. Set exact values

    In the inspector, enter X, Y, Width and Height. Click Set region to update the selection.

  3. Apply the crop

    Click Apply crop or press Enter. Escape cancels; Undo restores the previous image.

  4. Save an image

    Choose Save as… and PNG or another supported image format. Pick the destination and filename.

07 / Capture & images

Copy words from an image

Use Windows OCR to recognize text in a screenshot.

    Select a capture or import an image that contains readable text.

  2. Select Grab Text

    Choose Grab Text in the ribbon and drag around the words you need.

  3. Review recognition

08 / Video

Record your screen with audio

Choose the target and sound sources before starting.

  1. Switch to Video

    Select Video and choose Region, Window or Full screen.

  2. Choose sound sources

    Turn on System audio to include computer sound. Enable Microphone and select the intended device if you want narration. Webcam is optional.

  3. Start recording

    Click Record and select the requested region or window. A recording bar provides Pause and Stop controls.

  4. Stop and review

    Click Stop. The recording opens in the video editor, where you can preview, trim and export it.

09 / Video

Edit and export a recording

Remove the parts you do not need and add visual context.

  1. Open the recording

    Select a recorded or imported video from Recent or Library.

  2. Choose the moment

    Use the timeline to move the playhead. Split divides a clip at that position; trim controls change what is included.

  3. Add an explanation

    Use captions, timed annotations or Zoom & pan to guide attention. Preview the result and use Undo when needed.

  4. Export the edited result

    Use Save as… or the Export panel. Choose MP4, WebM or GIF and wait for the export to finish before closing the application.

10 / Audio

Record audio on its own

Capture a microphone, computer sound or separate sources.

  1. Switch to Audio

    Choose Audio in the capture bar and select the intended microphone.

  2. Choose additional sources

    Enable computer sound if needed. The Audio capture controls also support a second microphone.

  3. Start and stop

    Click Record audio. With Delay set to None, recording starts immediately. Stop when you are finished.

  4. Review the waveform

    The recording opens in Audio studio. Play it back and check the sound before editing or exporting.

11 / Audio

Split, normalize and save audio

Work on the waveform and export the edited mix.

  1. Open an audio item

    Select a recording from the library or import an audio file.

  2. Preview and split

    Play the clip, stop at the intended point, select the clip and use Split at the playhead.

  3. Adjust the mix

    Use track controls for level, pan, mute and solo. Normalize peaks and Match loudness are available for level adjustments.

  4. Save the result

    Click Save audio… or choose an audio format through Save as…. Export WAV, MP3 or M4A as appropriate.

12 / Audio

Use audio presets and effects

Explore a preset, then inspect the controls it applies.

  1. Choose the effect target

    Open an audio project. Select a clip for clip effects, or open Master effects for the combined output.

  2. Apply a preset

    Choose a voice preset and apply it. The effect rack shows the processing stages.

  3. Open the controls

    Select an effect and open its controls. The compressor offers threshold, ratio, attack, release and output gain.

  4. Listen before exporting

    Preview the result. Compare with bypass or Undo as appropriate, then save the edited audio.

13 / Guides

Create and export a step guide

Give every screenshot a title and an instruction.

  1. Start a guide

    Use New → Blank step guide to assemble one, or start Step Capture to collect screenshots as you click through a task.

  2. Add and arrange steps

    Use Add step or Capture more steps. Move steps up or down to put them in the intended order.

  3. Write the instructions

    Edit the guide title, each step title and the text below it. Edit image opens that screenshot for markup or cropping.

  4. Choose the output

    The guide inspector offers Word, PDF, PowerPoint, PNG and JPG. Choose a .saveit file when you want to reopen the editable guide later.

Find, rename and reopen your work

15 / Library & sharing

Choose the right save or export

Keep an editable project or write a file someone else can open.

  1. Choose the outcome

    For an image or guide you want to edit later, choose Saveit file (.saveit). Audio and video edits remain in the local library.

  2. Export a shareable file

    Save as… opens the available formats for the current project. Images include PNG, JPG, PDF, Word and PowerPoint; video offers MP4, WebM and GIF; audio offers WAV, MP3 and M4A.

  3. Pick the name and folder

    New exports start in Documents/Saveit Exports. Save It remembers your chosen folder for each format.

  4. Understand repeat saves

    The Save button identifies its format. After a file is saved in a session, another Save can overwrite that file. Use Save as… when you want a separate copy.

16 / Library & sharing

Keep Save It up to date

Check for a newer signed release when you are ready.

  1. Save any work in progress

    Finish an active recording or export before starting an update.

  2. Open Check for Updates

    Use Check for Updates at the bottom of the application. The check runs when you request it.

  3. Download and confirm

    If a newer version is available, choose Install Update. After verification, confirm Install and restart.

  4. Review the new version

    Save It reopens after the update. Your library and settings are preserved. If no update is available, the dialog reports that the app is up to date.
